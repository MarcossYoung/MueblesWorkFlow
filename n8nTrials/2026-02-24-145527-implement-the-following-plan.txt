│ Workflow Architecture                                                        │
│                                                                              │
│ [WhatsApp user sends message]                                                │
│          ↓                                                                   │
│ [WhatsApp Business Trigger]                                                  │
│   - text:      $json.messages[0].text.body                                   │
│   - sessionId: $json.contacts[0].wa_id  (phone number)                       │
│          ↓                                                                   │
│ [AI Agent — Tools Agent]                                                     │
│   ├── [GPT-4o LLM]                                                           │
│   ├── [Buffer Window Memory — keyed by phone number]                         │
│   └── [9 HTTP Tools → Spring Boot API]                                       │
│          ↓                                                                   │
│ [WhatsApp Send Message]                                                      │
│   - To: sender phone number                                                  │
│   - Text: agent response                                                     │
│                                                                              │
│ ---                                                                          │
│ N8N Setup (before importing)                                                 │
│                                                                              │
│ 1. WhatsApp Business credential — Configure in N8N with your Meta App        │
│ credentials (App ID, App Secret, access token, phone number ID)              │
│ 2. Meta webhook — Point your Meta App webhook to the N8N WhatsApp trigger    │
│ URL; subscribe to messages events                                            │
│ 3. N8N Variable — Settings → Variables → add BACKEND_URL = production        │
│ backend URL                                                                  │
│ 4. OpenAI Credential — Create credential named "OpenAI account" with API key │
│ 5. Import muebles-whatsapp-agent.json into Railway N8N                       │
│ 6. Activate the workflow                                                     │
│                                                                              │
